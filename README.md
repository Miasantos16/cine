# Base de datos: Cine

Base de datos `cine_proyecto` para **XAMPP** (MySQL / MariaDB).

Tablas: `peliculas`, `clasificaciones`, `generos`, `pelicula_genero`, `idiomas`, `formatos`, `estados`, `salas`, `horarios`, `funciones`, `usuarios`.

## Cómo importarla
1. Abre el XAMPP Control Panel y dale **Start** a Apache y MySQL.
2. Entra a http://localhost/phpmyadmin
3. Crea una base llamada `cine_proyecto` y ábrela.
4. Pestaña **Importar** → elige `cine_proyecto.sql` → **Importar**.
